# Fundamental Booster -- Personal Data Collector

## Overview

A beginner-friendly Python console project that collects user
information, demonstrates Python data types, memory addresses using
`id()`, and formatted output.

## Features

-   Takes user input (name, age, height, favourite number)
-   Displays each value with its data type and memory address
-   Shows an approximate birth year
-   Simple and clean console interface

## Technologies

-   Python 3

## How to Run

``` bash
python "Fundamental Booster project.py"
```
