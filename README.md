# Interactive Personal Data Collector

## Overview
This Python project collects basic personal information from a user through the console and then displays the collected data.

## Features
- Greets the user.
- Collects:
  - Name
  - Age
  - Height (in meters)
  - Favorite number
- Displays a summary of the entered information.

## Example Workflow
```text
welcome to the interactive personal data collector!
Please enter your name : John
Please enter your age : 18
Please enter your height in meter : 1.75
Please enter your favourite number : 7

Thank you! Here is the information we collected
```
## Requirements
- Python 3.x

## How to Run
1. Open a terminal.
2. Run the Python script:
   ```bash
   python filename.py
   ```
3. Enter the requested information when prompted.

## Learning Concepts Used
- Variables
- User input with `input()`
- Type conversion using `int()` and `float()`
- Output using `print()`
