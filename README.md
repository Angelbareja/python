# Interactive Personal Data Collector

## 📌 Project Overview

The **Interactive Personal Data Collector** is a beginner-friendly Python project that demonstrates how to collect user input using Python's built-in `input()` function and display the collected information back to the user.

This project is useful for learning:

* User input handling
* Data type conversion (`int`, `float`)
* Variables and data storage
* Output formatting using `print()`

---

## 🚀 Features

* Collects the user's name
* Collects the user's age
* Collects the user's height (in meters)
* Collects the user's favorite number
* Displays a confirmation message after collecting the information

---

## 🛠️ Technologies Used

* Python 3.x
* Jupyter Notebook

## 💻 Code Functionality

The program performs the following steps:

1. Displays a welcome message.
2. Requests the user's name.
3. Requests the user's age.
4. Requests the user's height in meters.
5. Requests the user's favorite number.
6. Displays a thank-you message.

### Sample Code

```python
print("Welcome to the Interactive Personal Data Collector!")

name = input("Please enter your name: ")
age = int(input("Please enter your age: "))
height = float(input("Please enter your height in meters: "))
favorite_number = int(input("Please enter your favourite number: "))

print("Thank you! Here is the information we collected")
```
