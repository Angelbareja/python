# # Interactive Personal Data Collector

## Overview
The Interactive Personal Data Collector is a beginner-friendly Python project that collects user information through the command line and displays it in a structured format. This project demonstrates the use of user input, data types, variables, and output formatting in Python.

## Features
- Collects user's name
- Collects user's age
- Collects user's height
- Collects user's favorite number
- Displays all collected information clearly
- Simple and interactive command-line interface

## Technologies Used
- Python 3

## How It Works
1. The program welcomes the user.
2. It asks for:
   - Name
   - Age
   - Height
   - Favorite Number
3. The entered information is stored in variables.
4. The program displays the collected information back to the user.

## Sample Output

```text
Welcome to the interactive personal data collector!

Please enter your name : John
Please enter your age : 22
Please enter your height in meters : 1.75
Please enter your favourite number : 7

Thank you! Here is the information we collected:

Name: John
Age: 22
Height: 1.75 meters
Favourite Number: 7
```
